# Stone Project Drive — Releases

Official installer releases for **Stone Project Drive** (desktop companion app).

Mount your company files as a drive in Finder or Explorer. The companion app and Stone Project settings check this repository for updates automatically.

Download the latest installers from the [Releases](../../releases/latest) page:

| Platform | File |
|----------|------|
| macOS | `StoneProjectDrive-{version}.dmg` |
| Windows | `StoneProjectDrive-Setup.exe` |

Installers only — no source code.
